## Selesai Hari Ini

### 1. Backend Laporan & Jadwal Kegiatan
- **Migration** `laporan_drafts` — tabel draft narasi laporan (JSON data per kegiatan)
- **Migration** `jadwal_harian` — tabel jadwal per hari (per kegiatan, per kelas opsional)
- **Model** `LaporanDraft.php` — relasi ke `kegiatan`, cast `data` as JSON
- **Model** `JadwalHarian.php` — relasi ke `kegiatan` dan `kelas`, cast `items` as JSON
- **Controller** `LaporanController.php` — 4 endpoint:
  - `GET /api/v1/laporan/{id}/draft` — ambil draft narasi
  - `POST /api/v1/laporan/{id}/draft` — simpan draft narasi

- **Routes** ditambahkan di `routes/api.php` (protected by `auth:sanctum`)
- **Fix collation** — `utf8mb4_unicode_ci` → `utf8mb4_general_ci` di `config/database.php` dan tabel baru

### 3. Jadwal Harian di Form Kegiatan (`Kegiatan.vue`)
- Input jadwal per hari dengan `jam_mulai`, `jam_selesai`, `kategori`, `pj`
- Tipe item: **Materi** atau **Istirahat** (dropdown)
- JP dihitung otomatis dari selisih waktu
- **Time cascade** — perubahan jam propagasi otomatis ke item berikutnya:

## Catatan Teknis

### Waktu Cascade Logic
```
onJamMulaiChange(dayIndex, itemIndex):
  1. Clamp start ≥ prev.jam_selesai
  2. If end ≤ start → auto-set end = start + 2h (materi) or +15m (istirahat)
  3. Update JP
  4. cascadeTimes(day, itemIndex + 1) → propagate ke semua item berikutnya
```

### Data Flow Jadwal
```
Kegiatan.vue (form) → saveJadwal() → POST /api/v1/laporan/{id}/jadwal
                                        ↓
                                    jadwal_harian table
                                        ↓
KegiatanDetailPublik.vue ← getJadwal() ← GET /api/v1/laporan/{id}/jadwal
BuatLaporan.vue         ← getJadwal() ← GET /api/v1/laporan/{id}/jadwal
```
